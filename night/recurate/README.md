# אצירה-מחדש עם מספרים — טיוטות (22.09.2026, סשן א')

התוכנית: `night/PLAN_DIGITS.md` — „תוכנית האצירה-מחדש". הבלוקים המאוצרים של הפקודות שספרותיהן שובשו
נכתבו מהטקסט השבור ולכן חסרי-מספרים (`key-facts-nodigits`). כאן, לכל פקודה, **טיוטת בלוק אחד עם המספרים**,
שכל מספר בו נקרא בעין מתמונת-העמוד של ה-PDF (`numbers_seen` ליד כל סעיף, עם מספר הסעיף במקור).

**כלום כאן לא נכתב לקורפוס.** סדר ההחלה, רק אחרי „תורך" מהסשן המנהל (הקורפוס פתוח בתור):

1. `python -m night.digitfix <doc_id> --read` (שתי קריאות בלתי-תלויות, ~$0.03 לפקודה) ← `--apply` — `raw_text` מתוקן.
2. הבלוק מ-`defs/<doc_id>.json` מחליף את `key-facts` + `key-facts-nodigits` (`replaces_sections`).
3. שערים: `night.curate.check(section, raw)` (ציטוטים, אוצר-מילים, בלי נושאי-סיכון, בלי שאריות) ו-`night.numbers`
   — **כל מספר בבלוק חייב להופיע ב-raw_text המתוקן**; מספר שנדחה ⇒ הסעיף חוזר לנוסח חסר-המספר עם ההערה.
4. `storage.vector_store.index_document(doc)` (upsert מקומי, בלי API), ואז שערי-הקורפוס: חבילה, `night.gate`,
   הסרגל, head-100 (עם ובלי המזוהמות), `routed_sectprobe --against sect7` — אפס אבודים; ממוצע+מקסימום מילות-חלון.
5. ביקורת-נאמנות בלתי-תלויה של הסשן השני מול ה-PDF (הלקח מ-wave-6: 6 ליקויים ששום שער לא ראה).
