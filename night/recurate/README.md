4. `storage.vector_store.index_document(doc)` (upsert מקומי, בלי API), ואז שערי-הקורפוס: חבילה, `night.gate`,
   הסרגל, head-100 (עם ובלי המזוהמות), `routed_sectprobe --against sect7` — אפס אבודים; ממוצע+מקסימום מילות-חלון.
