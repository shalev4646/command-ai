# ui_audit — הרצת האפליקציה בדפדפן וחיפוש פגמים שהעין תופסת

בדיקות ה-`tests/` קוראות את הקוד. הכלי הזה **מריץ** אותו: streamlit 1.58.0 עם
כפיל ל-backend, מונע ב-Chromium ברוחב 390, ומריץ על כל מסך בודק שמחפש פגמים
שאף assert לא היה תופס.

```
python3 tools/ui_audit/run_stub.py &          # מרים את האפליקציה על 8501
python3 tools/ui_audit/audit_selftest.py      # מאמת שהבודק בכלל רואה פגמים
python3 tools/ui_audit/sweep.py               # סורק 13 מסכים
```

`run_stub.py` מזייף את `backend` — הקורפוס ומודל ה-ONNX אינם נדרשים כדי
להסתכל על מסך, וזו כבר התבנית של `tests/test_scope_routes.py`.

## מה הוא מחפש

`occluded` · `duplicate-copy` · `contrast` · `small-target` · `clipped-text` ·
`off-screen` · `overflow-x` · `unnamed-control` · `placeholder-leak`

שתי הקטגוריות הראשונות אינן גנריות — הן בדיוק שני הפגמים שההרצה הראשונה של
הסקירה מצאה בעין: תוכן שמרנדר מושלם ומכוסה, ותוכן נכון שנאמר פעמיים.

## תריץ את audit_selftest.py לפני שתאמין לתוצאה

הבודק הזה דיווח **אפס ממצאים ב-13 מסכים** בזמן שהיה עיוור לשני באגים שכבר
נמצאו בעין. שלוש נקודות עיוורות, כל אחת נמצאה רק בהרצה מול פגם ידוע:

1. **`hidden()` פסל את כל האפליקציה.** לעטיפה `withScreencast` של Streamlit יש
   גובה 0, ובדיקת גודל-קופסה שרצה גם על האבות סימנה כל אלמנט בכל מסך כמוסתר.
   גודל נבדק עכשיו על האלמנט עצמו בלבד.
2. **רק אלמנטים בלי ילדים נבדקו.** טקסט ממשק אמיתי מכיל `<b>`, `<br>`, `<span>`
   — כך שכמעט כל מחרוזת דולגה. הוחלף ב-`owns()`: לאלמנט יש טקסט ואין ילד עם
   אותו טקסט בדיוק.
3. **`background-image` לא נלקח בחשבון.** האווטאר במגירה — כמעט-שחור על גרדיאנט
   זית בהיר, בערך 9:1 — דווח כ-1.03:1, והוביל את הרשימה בכל מסך. ניגודיות
   מדולגת עכשיו מעל רקע מצויר ונשפטת בעין.

`regress_check.py` (לא נשמר) הריץ את הבודק מול הבנייה שלפני התיקונים ואימת
שהוא תופס את שניהם. תבנית שכדאי לחזור עליה: **בודק שלא אומת מול פגם ידוע
מדווח „נקי" ואי אפשר להאמין לו.**
