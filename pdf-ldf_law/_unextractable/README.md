# מקורות שהחילוץ דוחה

11 קבצים ש-`ingestion.pdf_to_json.ingest` דוחה בשער הטקסט הדליל ("PDF סרוק עם שכבת
טקסט חלקית"). עשרה מהם עמוד אחד, בדרך כלל 20KB — פקודות קצרות אמיתיות (35.0204 מפרעה
לחייל חובה, 36.0314 תוספת דריכות) ולא רק דפי-ביטול, אבל שכבת הטקסט שלהם דלילה מכדי
להטמיע.

הועברו לכאן ב-2026-08-17 כי בתיקיית ההטמעה הם רצים ונכשלים **בכל בוט של האפליקציה**
(`_startup_ingest`), כולל בפרודקשן. ה-glob של ההטמעה אינו רקורסיבי, אז כאן הם שקטים.

לשחזר: OCR או הורדה מחדש מהאינדקס, ואז להחזיר לתיקייה הראשית.
